    Help
    • Keypad: type the bib number and press Enter as the runner crosses. The time is the moment Enter is pressed. The runner's name, age and sex show as you type; a bib that isn't registered is still recorded. A keyboard works too (Enter, Backspace, Esc to clear).
    • Turn the phone sideways for a wide view of the finish line. With Auto rotation the picture turns upright by itself, even with rotation lock on. If it comes out sideways or upside down, tap Rotate until it is upright.
    • Point the camera at the finish line, then drag the green band so it covers the area where runners' bibs pass. Only bibs inside the band are read.
    • Only the biggest number on a bib is read. Smaller numbers near it, like the event year or a number in a sponsor's logo, are ignored (shown in orange). Turn this off in Settings if your bibs have two numbers of the same size.
    • The time of a read is the moment the bib first appeared in the band. Adjust the timing input's skew in PikaTimer if needed.
    • Reads are saved on this device until PikaTimer confirms them, so a network drop does not lose them. The "queued" count shows how many are waiting.
    • Keep this page open while timing. If the network is down, the page cannot be reloaded until it is back (queued reads are kept).
    • The first time a device opens the link it has to accept the security warning, because PikaTimer uses its own certificate.
